# Select Next Loot Item (Without VanillaPlus)

A minimal Dalamud plugin that automatically selects the next loot item in the **Need/Greed/Pass** window.

## What It Does

- Selects the first unrolled item when the Need/Greed window opens.
- After you click **Need** or **Greed**, it automatically moves selection to the next item.
- After **Pass**, it moves to the next item only when the current item had not already been rolled.

## Why This Exists

This plugin is for users who only want the loot-item auto-selection behavior without running VanillaPlus.

## Installation

1. Open Dalamud settings.
2. Go to Experimental settings.
3. Add this URL to custom plugin repositories:
   - `https://raw.githubusercontent.com/Catphinaud/DalamudPlugins/refs/heads/main/pluginmaster.json`
4. Open the Plugin Installer.
5. Find **Select Next Loot Item (Without VanillaPlus)** and install it.

## Notes

- This plugin only handles selection in the Loot UI.
- It does not automatically choose Need/Greed/Pass for you.
